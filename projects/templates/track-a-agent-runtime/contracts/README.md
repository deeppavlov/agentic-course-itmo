# Контракты

| Файл | Протокол |
|---|---|
| `client-server.v0.schema.json` (или .yaml / .proto) | клиент ↔ сервер: подключение, сессия, сообщение, поток событий, отмена, переподключение |
| `harness-sandbox.v0.schema.json` | харнес ↔ сандбокс: provision, exec, events, result (ровно один), collect, release/cancel |

В каждом сообщении есть поле версии. Модель ошибок: ошибка команды / таймаут / ошибка сандбокса / сбой транспорта и политика ретраев для каждого класса.
